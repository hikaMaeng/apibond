## Native limitations and failures

This live LM Studio model rejects token IDs and token-ID batches with HTTP 400 (`'input' field must be a string or an array of strings`); proxy status/body match direct calls. It returns float arrays even when `encoding_format: "base64"` is requested; the proxy preserves that native behavior. Token transport and genuine base64 response preservation are covered by the HTTP fixture, not claimed as live-model support.

The implementation worker first observed four failing embeddings tests on base `cc70887` before implementing the route. An initial Clippy warning in the new test harness was fixed using a lexical mutex-guard scope; first-failure logs are preserved separately from passing logs. Root's independent final checks had no failures.
