2026-11-11, Asia/Seoul. Windows / Threadripper 3960X / 48 logical cores / 256 GiB RAM / Rust 1.96.0. Client, upstream mock and native proxy are separate processes. This measures HTTP transport, not model inference.

Requested producer pacing is 2ms; Windows timer behavior often yields roughly 15.5ms actual pacing. Raw JSON includes source-emission intervals and emission-to-receive latency so producer jitter is not attributed to relay overhead. Mixed-load rows are individual local runs with 50 source events; they do not establish a universal SLO.

Slow-client/cancellation fixture: eight responses held while each mock can emit 625 MiB. RSS/working set is read from the OS; compare steady 1s vs 3s values rather than the peak inherited from prior large-body tests.
- 8 workers: working set at 1s 238,096,384 bytes; at 3s 238,096,384 bytes; active 8 -> 0 after cancellation.
- 2 workers: working set at 1s 18,305,024 bytes; at 3s 18,305,024 bytes; active 8 -> 0 after cancellation.

JSON matrix errors: 0. Native APIs were tested against mock servers; no provider-backed model generation, internet latency, TLS throughput or fleet-scale performance was measured.

Reproduce: `cargo build --release --locked --bin apibond --example bench`; run `target/release/examples/bench target/release/apibond` and append `--stress-only` for the two-worker case (add .exe on Windows).
